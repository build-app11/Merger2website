Alat untuk membuat dan mengelola latihan. Halaman ini tidak ditampilkan di beranda.

Audiobook GeneratorBuat latihan audio sendiri: hasilkan transkrip dengan IPA di setiap kata, lalu simpan sebagai file JSON.
Buka alat → Video GeneratorBuat latihan dari video YouTube: ambil transkripnya, tambahkan IPA di setiap kata, lalu simpan sebagai file JSON.
Buka alat → Reading GeneratorAmbil teks bacaan dari teks biasa, file, foto dokumen, link web, berita, atau podcast, lalu kirim ke Sync Reader atau simpan sebagai JSON.
Buka alat → Pembuat index.jsonGabungkan semua file JSON pelajaran menjadi satu index.json untuk daftar latihan di beranda.
Buka alat → Pembuat bahasaTambahkan bahasa baru ke language.json: teks Indonesia diterjemahkan otomatis, diperiksa, lalu diunduh.
