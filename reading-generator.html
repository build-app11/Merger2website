Reading Generator

Ambil teks bacaan dari teks biasa, file, foto dokumen, link web, berita, atau podcast. Hasilnya bisa diedit, diunduh, atau dikirim ke Sync Reader untuk diberi audio, IPA, dan terjemahan.

File dibaca di browser, tidak diunggah ke server. PDF hasil scan (berupa gambar) tidak punya teks: pakai menu Scan dokumen.
Kamera langsung butuh HTTPS atau localhost dan izin kamera. Kalau tidak bisa dibuka, pakai Kamera bawaan atau Galeri.
OCR (tesseract.js) berjalan di browser. Data bahasa diunduh sekali saat pertama dipakai.
Hanya isi artikel yang diambil: menu, iklan, komentar, dan blok "Baca juga" dibuang. Halaman diambil lewat proxy CORS publik, jadi situs berbayar atau yang butuh login tidak didukung.
Whisper di server (bawaan bila server tersambung): server mengunduh audio episode dan memprosesnya, jadi cepat dan tidak membebani ponsel; hanya untuk episode dari daftar. Whisper di browser memakai CPU/RAM perangkat (transformers.js), jadi lambat di ponsel, tetapi bisa untuk file audio sendiri dan jalan tanpa server. Mulai dari 5–10 menit dan model tiny/base. Model diunduh dari Hugging Face sekali lalu disimpan cache browser. Kalau audio episode diblokir (CORS), unduh mp3-nya lalu pilih sebagai file audio.
Ketuk artikel untuk mengambil isi lengkapnya. Bila halaman artikel tidak bisa dimuat, dipakai isi penuh dari feed (kalau ada). Tanda ✓ menandai artikel yang sudah diambil.
